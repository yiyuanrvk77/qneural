# 问络 · 问题神经网络平台

一种不像对话框的提问产品：节点是问题，连线是问题之间的关系；双击任意节点进入“单点纵深”，像一条隧道一样逐层追问下去。支持鼠标、触屏和摄像头手势三种交互方式。

## 核心体验

- **神经网络式画布**：拖拽空白平移、滚轮/双指缩放、拖拽节点重排、拖拽节点上的连接点建立新链接。
- **单点纵深**：双击节点进入纵深视图，上下滑动换层、双指捏合展开深层提示、左滑卡片把纵深问题挂回网络成为新节点。
- **手势模式（摄像头）**：抬手唤醒粒子网络、指向节点查看问题、拇指与食指捏合进入纵深、纵深中挥手换层。开启后右上角显示摄像头小窗。
- **内置 AI 工作台（右侧面板）**：流式对话、把对话提炼为问题网络或加入节点纵深、自主规划（AI 拆解目标并逐条自动执行）、融合分析（相似度/创新度/融合概率）。
- **融合火花提示**：鼠标悬停在节点上时，画布显示虚线火花连线与融合概率气泡；高概率建议可一键接受为正式连线，并自动推送到飞书。
- **音阶模式（联觉）**：开启后单击节点会发声——节点类型决定音色，上下位置决定音高，在五声音阶内演奏。
- **产品能力**：多账号注册/登录、问题网络增删改、节点与纵深链路完整编辑、模板库一键套用、JSON 导入导出、自动保存与失败重试。

## AI 工作台（内置）

点击顶栏的 ✦ 按钮打开 AI 工作台，包含三个页签：

- **对话**：流式回复，支持 Markdown 与代码高亮；可一键「提炼为问题网络」或「加入当前节点纵深」。
- **规划**：输入目标，AI 自动拆解为 3-6 个步骤；可单步执行或「自动执行全部」，执行结果保留在本地。
- **融合**：选择两个节点，AI 评估相似度、创新度与融合概率并给出理由；建议保存在当前网络，可接受（自动建线）或忽略。

AI 能力调用 DeepSeek API。首次使用前请到「用户 → AI 设置」配置 API Key（也可以在 `data/config.json` 中手动填写，或设置环境变量 `DEEPSEEK_API_KEY`）。

### 飞书集成

在「AI 设置」中填入飞书自定义机器人 Webhook 地址后：

- 融合概率 ≥ 55% 的新建议会自动推送到飞书；
- 自主规划的每个步骤完成时推送进度；
- 保存设置时会自动发送一条测试通知验证。

### 记忆（学习基础）

「AI 设置」中的「记忆」字段会写入每次对话的系统提示词，AI 会持续参考你的长期偏好与背景。记忆随账号保存在 `data/db.json`，不会上传到任何第三方。

### 音阶模式

点击顶栏的 ♪ 按钮开启/关闭。开启后单击节点发声：节点类型（起点/输入/思考/行动）对应五声音阶的不同音级，节点在画布上的上下位置决定八度。使用 Web Audio 合成，无需联网。

## 快速开始

环境要求：Node.js 18 或更高版本（建议 20+）。

方式一：双击 `start.cmd`。

方式二：命令行启动

```bash
cd qneural
npm start
```

启动后访问 http://localhost:3000 。如果 3000 端口被占用，服务会自动尝试 3001–3010，并在控制台打印实际地址。

注册账号后会自动创建一个示例问题网络，也可以从左侧模板库一键创建。

## 数据与备份

- 所有数据保存在 `data/db.json`（账号、密码哈希、问题网络）。
- AI 配置（DeepSeek Key、飞书 Webhook）保存在 `data/config.json`，请勿外传。
- 会话密钥保存在 `data/secret`，请勿外传或删除；删除后所有登录态失效。
- 备份：直接复制 `data/` 目录，或在产品内使用“导出”下载单个网络的 JSON。
- 恢复：把 `data/db.json` 放回原位后重启服务，或在产品内用“导入”恢复单个网络。

## 手势模式说明

- 需要浏览器允许访问摄像头，且需要联网加载手势识别库（MediaPipe，托管于 jsdelivr CDN）。
- 若摄像头被拒绝或网络不可用，会自动回落到鼠标/触屏交互，不影响使用。
- 手势映射：
  - 手掌出现 → 唤醒网络，连线出现流动粒子；
  - 伸出食指指向节点 → 节点高亮，底部状态栏显示它的起点问题；
  - 拇指与食指捏合 → 进入该节点的纵深视图（再次捏合展开/收起深层提示）；
  - 纵深中食指上/下滑动 → 切换纵深层级。

## 技术说明

- 后端：Node.js 零依赖（仅使用内置模块），REST API + 静态文件服务。
- 前端：原生 HTML/CSS/JS，无构建步骤，无第三方运行时依赖（手势识别除外）。
- 账号：scrypt 加盐哈希存储密码；会话使用 HMAC 签名 Cookie。
- 接口：`/api/health`、`/api/auth/*`、`/api/me`、`/api/templates`、`/api/networks` 及 `/api/networks/:id`、
  `/api/config`（AI 设置）、`/api/conversations` 与 `/api/chat`（流式对话）、`/api/chat/extract`（对话提炼）、
  `/api/fusion/analyze`（融合分析）、`/api/plans`（自主规划）、`/api/integrations/test`（飞书测试）。
- 对话与规划数据保存在 `data/db.json`；融合建议保存在问题网络数据中（`fusionSuggestions` 字段）。

## 部署提示

本产品默认以“本地部署”方式运行。若要部署到公网：

- 建议在反向代理（如 Nginx/Caddy）后运行，并配置 HTTPS，否则摄像头 API 不可用；
- 设置环境变量 `PORT` 指定端口；
- 为 `data/` 目录配置定期备份。
